Latest Update

Update 1.0.3 — Lanka Arc & Python Backend

The complete Lanka rescue storyline is now playable, featuring 67 new scenes with strategic choices and multiple endings. Python backend for save/load management is now available.

Major additions:

  • Complete Lanka Rescue Arc: War councils, ocean crossings, infiltration strategies, and Ravana battles (54 new scenes).
  • Strategic Planning: Multiple approaches to the rescue (direct assault, scouting first, deception, divine aid).
  • Ocean Crossing Mechanics: Choose between bridge sacrifice, Hanuman's guidance, or secret sea routes.
  • Multiple Ravana Encounters: Strategic vs. direct combat approaches with different outcomes.
  • Triumphal Ending: Escape Lanka and return to Ayodhya (Scene 121 epilogue).
  • Python Backend (data.py): RamayanaGameData class for managing JSON save files, validation, and listing.
  • Save Game: Export your progress as a JSON file with a single click.
  • Load Game: Import a previously saved JSON file to resume your adventure.
  • Day/Night Mode: Toggle between day and night visual themes with persistent preference storage.
  • Full storyline now covers Exile (Banwas) from beginning to victorious return.
